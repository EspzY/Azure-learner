## Immutable identity

- Friendly stocky anthropomorphic shark; large head, same short-legged proportions and basic polished 3D illustration style.
- Blue/turquoise skin; long broad snout with two nostrils, original oval eyes and pale lower jaw; characteristic broad toothy smile. Preserve the original sharper scalloped/pointed tooth treatment, not rounded bead-like teeth.
- Warm beige hands, turquoise sweater, dark trousers, original dark sneakers with light lacing/details. No new shoe stripes, glove/flipper substitution, brands, slogans or costume changes.
- Consistent soft light, volume, materials and silhouette. Correct hands/anatomy, no extra limbs or impossible prop contact. Props never conceal identity defects.
- Transparent delivery, clean edges on white, navy and checker backgrounds; no opaque matte, colored fringe, detached pixels, unwanted shadow plates, text or logo.

## Actual production outcome

Four real reference-conditioned image generations explored three pose concepts: initial/revised wave, thinking, revised explaining right. Three final candidate masters and six optimized WebP display variants are delivered in `public/design-review/characters/v1/`. The initial superseded wave remains in external process evidence, not the active registry.

**Zero new poses are production approved.** The fresh independent art review found tooth/face fidelity drift, added shoe stripes in the thinking sample and cyan/blue/orange fringe/detached residue at alpha edges. Revised explaining corrected some shoe detail but did not resolve dentition/export acceptance. Plausible same-character resemblance is insufficient for the owner's strict identity contract. Near-opaque alpha values alone are not a defect; visible matte contamination is the issue.

The real images are visible only in the explicitly rejected Character Bible gallery. Do not expand the library by generating nineteen more inconsistent characters. Available image-generation capacity was used; the unresolved constraint is identity/export quality, not unavailable tooling. No CSS rotation/mirror is counted as a pose. Technical resizing/WebP encoding changes no anatomy or expression and does not repair/relabel a rejected master.

## State-to-character contract

Existing authoritative state selects a semantic intent, never random rerenders. Welcome/theory/investigation/uncertainty/support/completion may eventually map to approved poses. Current resolver uses only the canonical fallback for all safe states. Active independent, unknown readiness or storage conflict suppresses the character in the guidance specimen; no supportive pose can reveal correctness. A pose cannot start, complete, award or amend learning. Minimize/restore is an ephemeral visual preference; native essential instructions stay available.

No celebratory expression without existing verified completion, no actual-compromise/telemetry implication, no automatic popup every navigation. Motion is optional and subtle; reduced motion removes transitions. The full library requires future art-owner approval and independent identity/export recheck; this PR does not claim it complete.
