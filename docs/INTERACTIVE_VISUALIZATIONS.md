## Live architecture lens

Use the existing model's relations(world) plus explicit policy-applicability projection. Nodes derive from actual scopes/groups/plans/apps/policies. Hosting dependency has a separate style and inspection explanation from membership. Group metadata and hosting location remain separate labels. The graph changes only when the world changes; a denied command appears in history/receipt, not a deployed node. Policy inspection highlights assignment scope/type/allowed locations, not a physical firewall.

XYFlow supports zoom/pan/fit/selection with stable IDs. Native node/relation lists provide inspection and portal links without dragging; small screens can switch to list while retaining graph access. Relation selection shows endpoints, meaning and source-backed limitation, with actual property data. No layout coordinate implies geography or Azure deployment location. Test every resource/edge against the world, failed-operation exclusion, replay and accessible selection. Human diagram comprehension remains an outstanding review gate.
