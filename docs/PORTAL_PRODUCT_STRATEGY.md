## Learn, Practice, Understand

One operational workspace connects original teaching, a bounded Portal-inspired inventory and causal diagrams. A learner studies an abstraction, compares responsibility, selects a platform for a workload, creates validated resources, inspects a real rejection and explains the resulting dependency. An unfamiliar requirement tests application separately from guided work. A quest, page visit or diagram animation is never evidence of competence.

## Design decision

Use dense, restrained Portal conventions: global search/header, dockable service menu, breadcrumbs, contextual command bar, tables, resource menus and review/create. AzureLab identity and a persistent simulation indicator prevent confusion with a live tenant. No credential form, Microsoft logo, copied portal code or screenshot is shipped.

Fluent UI React Components **9.74.11** was evaluated from official npm metadata on 2026-10-24: MIT; React and React types >=16.14 <20 include this repository's React19.3.1. The package's unpacked size is 2,229,574 bytes, not its browser bundle size. Native semantic controls and the existing Lucide/XYFlow dependencies are selected for this bounded subset: tables, forms and native dialogs need no additional component runtime, while scoped tokens provide consistent density/focus. Fluent is not a guarantee of Portal fidelity. Re-evaluate for genuinely complex grids/comboboxes, with measured benefit. [Publisher/license](https://github.com/microsoft/fluentui) and [package metadata](https://www.npmjs.com/package/@fluentui/react-components) are reference-only; nothing is copied or installed.
