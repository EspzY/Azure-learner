# Shared Portal capability matrix — observed9 November2026

Source baseline PR71 `0538b40cc51af634e71182014e65bdb932936c70`. Reviewed actual v2 registered commands, resource projections/UI, every Laboratory3.0–3.7 contract/dispatch, Portal controllers, storage adapters, Studio and lifecycle presenters. This matrix describes actual simulator operations, never live Azure APIs. **R** is read/inspect; **C/U/D** create/update/delete; **A** analysis; **link** an actual UI entry. Reset is workspace-wide with preserved history, not individual-resource Delete. All existing historic model evaluators remain frozen.

Capability availability is version-bound:3.0 Storage;3.1 VNet/subnet/NSG;3.2 peering/UDR;3.3 NIC/policy;3.4 VM/disk;3.5 Firewall;3.6 rule remediation;3.7 topology remediation. Common catalogue gates match these actual contracts; inspecting an old workspace never upgrades it. The Studio can read older supported versions without inventing their missing resources.

The minimum next useful step is **one versioned Web/plan/settings vertical in Laboratory**, followed by the shared command/workspace facade and one new course-bound evidence pilot. General resource deletion, new Azure services and broad course migration are not prerequisites for the first entry-surface convergence and are not smuggled into this PR.
