# Current operational capability matrix — Laboratory3.9

This matrix applies only to the explicitly selected `laboratory@3.9.0` World. New client starts recommend3.9; existing3.0–3.8 and course-v2 workspaces keep their original models. A catalogue entry never activates another model. “Inspect” means the actual configured record and original technical evidence, not Azure runtime.

The command union is [v39/contract](../src/laboratory/v39/contract.ts). The Portal exposes every supported [delivery operation](../src/features/laboratory/integrated-delivery.tsx) and [data operation](../src/features/laboratory/integrated-data.tsx) through actual-World selectors and the common Review/Create/Save/Delete pipeline. The exact reused modules define40 delivery and22 data operations; their pure proposals become original receipts only through the3.9 host. The [integration contract](LABORATORY_INTEGRATED_APPLICATION_CHAIN.md), [delivery profile](APPLICATION_DELIVERY_PLATFORM.md) and [data profile](DATA_SERVERLESS_DOMAIN.md) describe boundaries and source verification. Author/native/PG results and pending delivery gates are separate in [QA](quality/INTEGRATED_APPLICATION_CHAIN_QA.md).

Database analysis distinguishes unknown source-egress IP, explicit configuration denial and consistent supported hypothetical IP/TLS configuration. It never discovers an outbound App Service address or authenticates. Function analysis returns only declared synthetic text and never executes user content. Results bind actual workspace/model/revision and invalidate on configuration change.

The3.9 host canonically checks accepted data proposals for semantic no-ops before revision/commit. JSONB key order cannot turn a same-value Function update into a false accepted change or a receipt that disagrees with replay. This changes the new host boundary; it does not rewrite or repair old models or histories.

All families share one World, monotonic ID counter,96 active records and512 original events. Reset clears active records while retaining original event history and increasing identity allocation. Deletes retain Create origin and never reuse IDs. Plans share a case-insensitive namespace per RG; Web/Function App names share one conservative case-insensitive namespace across the local World, without checking global Azure availability. No new course work, guide, assessment, learning state, XP or inventory authority is created.
