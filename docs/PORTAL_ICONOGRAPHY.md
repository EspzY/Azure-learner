### Rights assessment and limits

The actual official V24 archive (SHA256921594ccd1bf3d9c0a1bd7b6d924e050551a59342f2b353bb74bdcf761c35141) and its bundled Microsoft_Terms_of_Use.pdf were inspected, not just filenames. Both the current public terms and bundled terms permit architectural diagrams, training materials and documentation while reserving other uses. This implementation uses original Microsoft service identities solely inside explicitly identified, fictional Azure training exercises and their explanatory diagrams. It does not use those assets as AzureLab branding, unrelated product symbols or marketing endorsement. This is a bounded interpretation of the express training-material permission, not a blanket software-UI license or external legal approval. Reuse outside these educational surfaces requires a fresh rights decision. Azure SVG bytes/geometry/palette/ratio stay unchanged; no crop/rotation/recolour.

System/action glyphs are separately sourced from Microsoft Fluent System Icons, MIT, pinned package1.1.344 and upstream revision f1260014e8a4fcfa6777182fd6cf082fc5e952d8. The official repository LICENSE is retained. Monochrome system tint follows context; Azure service images never use masks/tint. No new runtime package, font or CDN.

Native SVG images have no filter, mask or colour override; Fluent action SVGs use a same-origin monochrome mask. No runtime icon package or CDN is added.
