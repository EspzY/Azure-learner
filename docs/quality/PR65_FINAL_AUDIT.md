## Open finding

**PR65-AUDIT-01 — MAJOR — ambiguous policy endpoint identities.** In [endpoints.tsx](../../src/features/laboratory/endpoints.tsx), `nicLabel` contains only NIC name, private IP and subnet name. Resource-group/subscription/VNet scope and stable NIC identity are absent from the source/destination options and the result. All three visible fields may legitimately repeat across distinct groups and overlapping VNets.

The independent Playwright probe created every positive resource through the ordinary UI: `rg-audit-a` and `rg-audit-b`, each with `vnet-duplicate` (`10.90.0.0/16`), `subnet-duplicate` (`10.90.1.0/24`), and `nic-duplicate` (`10.90.1.10`). It also created `nic-source` (`10.90.1.11`) in the first VNet. Both destination options displayed exactly `nic-duplicate · 10.90.1.10 · subnet-duplicate`, although their actual IDs were `nic-4` and `nic-8`. Selecting `nic-4` produced **Allowed by modeled network policy**; selecting `nic-8` produced **Undetermined / Unsupported**. Both results displayed the same destination text. The underlying endpoint/route guard correctly rejected the overlapping other-VNet path; the user cannot reliably choose or identify that path in this presentation. Analysis made no World/event/receipt change.

Required correction: show sufficient actual NIC and parent scope, including a stable identity, in both selectors and results; retain meaningful resource inspection links. Add a native regression with same names/IP/subnet names in different scopes, proving distinct visible identities, correct ID binding and the different actual outcomes. Recheck compact wrapping, keyboard and Axe after the longer labels. Preserve the original probe and finding, then renew the stamp and independent review.

Original independent probe artifacts remain outside implementation: `/workspace/azurelab-pr65/audit/identity-probe.mjs`, `identity-probe.json`, `identity-nic-4.png`, `identity-nic-8.png`. Both result screenshots were personally inspected. They show the identical endpoint text with different outcomes.
