Record each row as matched documented behavior, supported approximation, educational enhancement, unsupported or unverified. Do not average these into an unmeasured fidelity percentage.

| Workflow              | Intended match                                                                                  | Approximation / enhancement                                                                                               | Explicit exclusions                                                                                   |

Record whether they locate the correct service/scope without coaching, explain why metadata does not host an app, diagnose the actual denial and distinguish configuration from deployment. A wrong mental model, hidden essential control, misleading success or inability to find the task is a release-blocking defect requiring iteration. Automated functionality and implementing-agent screenshots are supporting evidence, not that human sign-off.
