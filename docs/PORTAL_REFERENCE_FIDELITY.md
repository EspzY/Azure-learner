### Reproducible owner walkthrough

1. Open the ordinary feature-preview root → Azure Fundamentals course → **Free sandbox**. Home shows actual supported services, clear training identity and current-session history.
2. Search **Resource groups**; ArrowDown/Enter opens the actual list. Create → Subscription → resource-group name → Region → Review + create → Create. Open linked metadata/members and follow breadcrumbs; review does not mutate resources.
3. Open **Virtual machines** → Create. Inspect Basics, Disks, Networking, dry review, then create the supported local bundle. In Overview inspect Essentials, Disks, Networking, Properties and the actual operation receipt. Follow linked disk/NIC/group objects. No real VM or connectivity is asserted.
4. From the course Service Types practical activity start the existing PaaS mission. Read/recall SavvyShark's brief. Create a group; attempt the plan in a denied region; inspect the actual receipt and applicable custom policy; choose a correction. Create the dependent Web App and inspect its real hosting relationship in Architecture Explorer.
5. Open the app → Environment variables → Edit → Save draft. Technical inventory/storage stay unchanged until explicit Apply. Inspect the result/receipt and reload. Use Properties and linked resources to verify context.
6. Minimize the coach to reclaim workspace; reopen without losing the mission. Return to the exact course debrief and resume/reload. An independent challenge retains its changed requirements and no solution highlights.
