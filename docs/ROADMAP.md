# Roadmap

## Phase 0 — foundation

One responsive workbench, accurate hierarchy, contextual inspector, deterministic group creation, original knowledge check and repeat-safe local XP. Toolchain, documentation, CI definition and accessible alternatives. No live learning services or production deployment. Automatic branch previews were explicitly approved during delivery.

## Phase 1 — validate learning and one consequence

1. Test with a small learner group: independent explanation of scope versus region, observed friction and misconceptions. Include keyboard, screen-reader and mobile sessions with consent.
2. Add one Azure Policy-inspired allowed-location scenario: predict, trigger and resolve a denied resource configuration. Distinguish group metadata policy from resource-location policy. Include deterministic replay, explainable validation, scenario-version fixtures and an independent assessment.

Version original modules and sources; add typed locale dictionaries when English begins. Define attempts/hint usage without equating guidance with mastery. Keep local persistence until account/privacy needs are understood.

Exit criteria: learner explains the distinction and resolves the failure unaided; deterministic replay; keyboard/mobile checks; source review; quality gates pass. No full catalogue or assistant integration yet.

## Phase 2 — personal persistence

Verified attempts, delayed retrieval and progression ledger. Evaluate backend/auth, then request authorization before provisioning. Export/deletion and honest trust labels for local imports. Add narrow network/compute/storage scenarios based on learner needs.

## Phase 3 — certification and optional metadata

Broader versioned AZ-900 coverage before AZ-104/AZ-305. Readiness uses independent performance, retention, coverage and uncertainty. Validate Learn terms/auth before activating the optional metadata-only adapter. Original teaching remains independent.

## Phase 4 — organizations

Memberships, isolation, privacy/retention, administration and accessibility review. Optional opt-in rankings with transparent cohorts/scoring. Enterprise rollout is a separate product/security decision.

Reconsider 3D only for an educational question 2D cannot explain well. Hosting, production services and paid infrastructure require separate authorization.
