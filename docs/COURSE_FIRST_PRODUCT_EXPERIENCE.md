4. Continue to “Fra tjenestevalg til hosting og scope”. Read the applied prerequisite bridge and explicit lab brief. Start the lab; the real Portal opens with a named Guided Lab and measured global-search outline. The course return remains visible.

Review is dry; explicit Create must produce an accepted receipt. The group overview describes actual scope/metadata.
6. Open App Service plans/Create, choose that group, a valid new plan name and North Europe for the controlled policy investigation. Review and explicitly Create. The real denied receipt identifies type, scope, requested location, assignment and unchanged world. The denied plan is absent from inventory.
7. Inspect Policy from that receipt/guide. Read its scope and allowed resource location. Choose a correction yourself, create a plan in West Europe, then create a new Web App referencing the accepted plan. App OS/location derive from the plan, not group metadata. This is supported configuration, not code deployment or runtime health.
8. Open Architecture Explorer and select the actual app→plan hosting relation using graph or semantic list. Distinguish it from group membership and metadata/resource locations. The lab becomes guided-satisfied only when all technical and inspection predicates hold.
9. Return to the course. The exact practice topic contains actual group/plan/app names, a causal debrief and retained-customer-responsibility reflection with wrong/correct feedback. Leave/reload/Back/Forward to verify the context and committed work persist. Exiting earlier shows unfinished/resume instead.
10. Start the existing changed independent challenge. It presents different scope/location requirements and ordinary Portal controls without guidance highlights. First/help/retry/abandon/replay distinctions remain. Theory/journal use is assistance; no new XP, Microsoft completion or mastery claim is emitted.
11. Revisit computing: all six substantial units, original experiments, journal and changed assessment remain available without WebGL. The free Portal does not force a lab; a URL lab hint without a validated session cannot create one.
