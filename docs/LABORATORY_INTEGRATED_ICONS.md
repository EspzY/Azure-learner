# Laboratory3.9 service-family artwork

The3.9 Portal uses seven additional original Microsoft Azure V24 family SVGs through the existing central icon manifest and unchanged renderer. They are local assets, not a runtime icon host or new package. Child configurations explicitly reuse their actual parent family; the owned FC1 plan uses the existing App Service Plan identity. The nonsecret local database binding uses the existing licensed Fluent settings glyph, not an invented Azure service. The mixed database-firewall catalogue uses that honest configuration glyph; actual rows use their typed PostgreSQL or SQL server family.

Their use here is a bounded interpretation of that permission for service identities inside independent technical training exercises; it is not blanket permission for product UI, branding or marketing.
