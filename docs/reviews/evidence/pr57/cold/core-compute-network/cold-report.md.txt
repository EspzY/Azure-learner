Reproduce: Start Peering Topology guide → Have both A/B sides selected; select B overlap10.84.0.0/17 and target VNet B → Predict not fulfilled and Run.

Learner must reconcile correct table with a prominent explanation of a different failed premise; weakens cause-based diagnostic practice.

Suggested correction: Use the actual first failed premise (address overlap), selected target and side status in result explanation.

### F2 · P2 · AVD zero-host result uses ambiguous generic capacity headline

Route: `/learn/compute?topic=desktop`. Exact text: “Noe arbeid eller kapasitet gjenstår”

Reproduce: Start AVD explorer → Use pooled/RemoteApp,workspace registration and assigned user → Run with2hosts,then change declared sessionhosts to0,predict partial and Run.
